## Basic Details

### Team Name: BRAINLESS CREATURES

### Team Members

* **Team Lead:** RIFA T
* **Member 2:** Anna Maria

### Project Description

**UNKNOWN VIRUS** is a colourful website that looks like a normal study and campus-management platform at first glance. 📚

But there is a twist! Behind the innocent-looking **CampusVibes** interface is a fun prank website where users can upload and display funny photos of their friends with hilarious captions.

### The Problem (that doesn't exist)

Students already have plenty of study websites.

But what happens when studying becomes **too serious**?

What if someone needs a completely unnecessary website to make their friends laugh instead of actually studying?

**That extremely important problem definitely needed solving.** 😂

### The Solution (that nobody asked for)

We created **UNKNOWN VIRUS** — a suspiciously colourful website disguised as a student productivity platform.

It looks like a useful campus website with timetables, notes, attendance and other student-related features. But underneath all that productivity is a completely unnecessary entertainment section where funny photos of friends can be displayed.

Because sometimes, **laughing at your friends is more important than studying.** 😌
